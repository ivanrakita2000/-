# ПЕРЕКУП v9

Мобильный прототип игры про перекупа автомобилей.

## Что добавлено в v9
- 260 моделей автомобилей.
- Реальный осмотр автомобиля до покупки.
- Тест-драйв: продавец может согласиться или отказаться.
- Контекстный чат продавца: ответы зависят от вопроса.
- Паспорт купленного автомобиля.
- Сравнение с похожими объявлениями/конкурентами.
- Статистика сделки и потенциальный результат.
- Отдельная вкладка «Достижения» с выполненными и невыполненными целями.
- Поездки между городами с расходами и временем.
- Игровые сутки примерно 6 минут реального времени.
- Одноразовые действия в гараже: после диагностики, ремонта, полировки, химчистки и покраски дисков выполненная операция исчезает.
- Диагностику СТО нельзя бесконечно покупать повторно для одной машины.
- Подготовка автомобиля к продаже — отдельный финальный этап.

## Важно
Фотографии пока не являются полноценным набором из нескольких кадров для каждой из 260 моделей. Для ряда моделей используются проверенные модельные изображения, а там, где отдельного файла нет, используется изображение марки. Перед коммерческим релизом фотобазу нужно заменить на полноценные комплекты конкретных автомобилей с проверенными правами использования.

## Запуск
Откройте `index.html` в браузере или разместите файлы на GitHub Pages.

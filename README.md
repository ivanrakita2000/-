# ПЕРЕКУП — первый прототип

Мобильный веб-прототип игры про перекуп автомобилей.

## Как запустить через GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи `index.html`, `style.css` и `app.js` в корень репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери `Deploy from a branch`.
5. Выбери `main` и папку `/ (root)`, затем Save.
6. GitHub выдаст ссылку на игру.

Прогресс гаража хранится в браузере через localStorage.

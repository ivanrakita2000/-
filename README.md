# ПЕРЕКУП v8

Прототип мобильной игры про перепродаж автомобилей.

Добавлено: 90 моделей, 10 российских городов, рынок по городам, фильтры, сортировка, избранное, Автотека, VIN-проверка, контекстный чат продавца, гараж, диагностика, ремонт, подготовка, собственные объявления, просмотры/избранное, игровое время и сон.

Фотографии в прототипе привязаны к марке/семейству автомобиля и берутся из открытых интернет-источников. Перед коммерческим релизом нужно заменить их на изображения с подтверждёнными правами использования. Для некоторых семейств пока используется одна базовая фотография, поэтому галерея сохраняет идентичность автомобиля, но не является полноценным набором пяти разных кадров одного экземпляра.

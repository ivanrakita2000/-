# ПЕРЕКУП v4 — рынок + уникальные автомобили + гараж

Главное изменение: каждое объявление представляет уникальный экземпляр автомобиля. После покупки его ID помечается как проданный и старое объявление исчезает. Автомобиль переносится в гараж. Из гаража его можно подготовить и продать. Старое объявление не восстанавливается.

Данные гаража и купленных экземпляров сохраняются в localStorage браузера.

Для следующего этапа потребуется серверная база данных, если рынок должен быть общим для всех игроков: тогда покупка одного экземпляра должна атомарно снимать объявление с сервера, чтобы два игрока не могли купить одну машину одновременно.
